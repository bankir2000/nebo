# Небо — офлайн-версія

Копія застосунку з файлу `index (31).html`, перейменована на «Небо».

## Що вже зроблено
- `index.html` — застосунок. Назву змінено на «Небо», шляхи переведено на локальні файли.
- `manifest.json` — опис для встановлення на головний екран.
- `sw.js` — сервісний воркер: кешує всі файли, щоб застосунок працював без інтернету.
- `icons/icon.png` — значок із гербом Сумської області.

## Що потрібно додати вручну
1. **Бібліотеки** у папку `lib/` (на комп'ютері з інтернетом):
   - `tailwind.min.css` — з `https://cdn.jsdelivr.net/npm/tailwindcss@2.2.19/dist/tailwind.min.css`
   - `vue.js` — з `https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js`
   - `vue-the-mask.js` — з `https://unpkg.com/vue-the-mask@0.11.1/dist/vue-the-mask.js`
2. **Герб** — значок уже встановлено (`icons/icon.png`). Щоб змінити, замініть файл іншим PNG з тією самою назвою.

## Як працює офлайн
Відкрийте застосунок один раз з інтернетом — сервісний воркер збереже файли. Далі він запускатиметься без зв'язку. Застосунок потрібно розміщувати через `https://` або `localhost`, інакше сервісний воркер не спрацює.
